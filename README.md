## Topics Explored

- **Hardware and Software:** Input-Process-Output-Storage (IPOS) model, hardware components, system software, application software, and utility tools.
- **Terminal Operations:** Navigation, directory manipulation, file creation, inspection, pipes, and standard flags on macOS.
- **Operating System Concepts:** Process monitoring, PID identification, memory, file permissions (`rwx`), and system responsibilities.
- **Program Execution:** Differences between compiled languages and interpreted languages, bytecode, and running scripts with Python 3.
- **Data Representation:** Manual binary, decimal, and hexadecimal conversions, text encoding (ASCII and UTF-8), and an interactive Python converter tool.
- **Version Control:** Repository initialization, staging, commits, branch management, pull requests, and Git collaboration.
- **Networking:** Network scopes (LAN, MAN, WAN), protocols, DNS resolution, ping connectivity testing, and packet routing.
